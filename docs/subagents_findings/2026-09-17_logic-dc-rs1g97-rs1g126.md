# Logic DC RS1G97 / RS1G126 (2026-09-17)

Hypothesis discarded: `seelim_dc.py` / `oe_timing.py` are not in tree. Part yaml was a stub (`tp` / `supply_current` / `input_thresholds`), not `icc`/`ii`. Owner is `lim`, not `seelim`.

Root causes:

1. `generator_setup.setup_dc` did not exist. Every Ariff/RS0204 DC `run()` ImportError.
2. `configurations.py` annotated `ScopeDevice` before the class. `load_family("logic")` died via runner -> mso -> scope_setup.
3. Ariff DC hardcodes AWG CH1/CH2 AND-gate holds. RS1G97 is 3-input Schmitt; RS1G126 has OE. Unused inputs must not float.
4. DEMO does not call `TestSpec.run`, so it can look green while START fails.

Fix: `ate/core/logic_model.py` + `ate/tests/logic/dc.py` driven by part YAML (`logic_inputs`, `oe`, truth, isolation, `vcc_sweep_list`). SIM in `python -m ate.core.check_logic_dc`. Limits from in-repo extract only. No colleague-tree scrape. No `vih_vil` on RS1G97. No inherited RS1G08 VOH tables.
